## Antes de empezar

Necesitas:

- Una cuenta con licencia de Copilot Studio (o trial activo).
- Acceso a un entorno de Power Platform.
- Un navegador moderno (Edge o Chrome recomendados).

## Crear el agente

<!-- TODO: Paso a paso con capturas -->

1. Accede a [copilotstudio.microsoft.com](https://copilotstudio.microsoft.com).
2. Selecciona **Crear** → **Nuevo agente**.
3. Dale un nombre descriptivo y una descripción clara de su propósito.
4. Configura las instrucciones iniciales — esto define el comportamiento base del agente.

:::tip
Las instrucciones iniciales son el equivalente al "system prompt". Dedica tiempo a redactarlas bien — un buen prompt base marca la diferencia entre un agente útil y uno mediocre.
:::

## Probar el agente

El panel de pruebas integrado te permite conversar con tu agente en tiempo real. Úsalo para:

- Verificar que las respuestas son coherentes.
- Probar flujos de temas específicos.
- Identificar puntos donde el agente se pierde.

## Siguiente paso

Con el agente creado, el siguiente paso es entender cómo funcionan los **temas y nodos** — la estructura que controla el comportamiento de tu agente.
