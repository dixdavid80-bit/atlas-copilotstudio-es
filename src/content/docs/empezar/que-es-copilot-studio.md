## En una frase

Copilot Studio es la plataforma de Microsoft para crear agentes conversacionales (chatbots con IA) sin escribir código, integrados nativamente con el ecosistema Microsoft 365 y Power Platform.

## Qué puedes hacer

- **Crear agentes conversacionales** con interfaz visual de arrastrar y soltar.
- **Conectar fuentes de conocimiento** (SharePoint, sitios web, archivos) para respuestas basadas en IA generativa.
- **Integrar con Power Automate** para ejecutar acciones reales (crear tickets, enviar correos, consultar datos).
- **Publicar en múltiples canales** — Teams, web, WhatsApp, Facebook Messenger.
- **Extender Microsoft 365 Copilot** con plugins y acciones personalizadas.

## Qué NO es

- **No es un chatbot genérico** tipo ChatGPT — es un builder de agentes con lógica de negocio.
- **No es solo Power Virtual Agents renombrado** — la arquitectura ha cambiado radicalmente con la integración de IA generativa.
- **No reemplaza a un developer** para integraciones complejas — pero cubre el 80% de los casos sin código.
